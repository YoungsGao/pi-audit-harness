## 复现命令

在 `desktop` 目录执行：

```powershell
npm ci
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test tests/*.test.mjs
npm run build
npm run lint -- --max-warnings=0
.\node_modules\.bin\electron-vite.cmd build --config electron.scan-test.config.ts
node tests/run-scan-electron.mjs
npm run test:qa04
```

普通 Electron 测试不依赖公开 GitHub 下载；test:qa04 额外要求可访问公开 GitHub、可用 Git，并覆盖配置 ping、真实克隆、缺 Git 提示和本地回退、SQLite 队列、三类 SSE、报告及不同 PID 恢复。

测试目录、报告产物、数据库、安装包、node_modules、个人学习资料与会话交接不随源码提交。技术文档索引由 `node docs/technical/assets/gen-index.mjs` 生成，推送前检查其与目录一致。
