## 2. 接口契约

`POST /code/query`沿用本地bearer及`{ok,requestId,data/error}`。CLI只连接回环地址，不接受任意URL、SQL、shell或SDK目录。

```json
{"operation":"definition","language":"java","projectId":"已有项目ID","runId":"已有任务ID","filePath":"demo/Web.java","line":8,"column":24,"maxResults":20,"fallback":false}
```

| operation | 额外输入 | 行为 |
| --- | --- | --- |
| capabilities/status | 无 | 读取能力/状态，不启动建图 |
| prepare | 无 | 校验或生成当前快照投影 |
| read | filePath、line、endLine | SQLite固定原文，最多80行/12000字符 |
| search | text | 字面量搜索，不改成上游符号FTS |
| symbols | filePath | 符号、限定名、签名和真实位置 |
| definition | filePath、line、column | 准确调用token的目标，歧义时多候选 |
| references | filePath、line、column | 方法调用引用，明确GRAPH_REFERENCES_PARTIAL |
| incomingCalls/outgoingCalls | filePath、line、column | 直接调用，每个调用点独立 |

每次校验项目/任务/快照归属与原文SHA256。相对路径必须在manifest内。行列从1开始，列UTF-16，end排除末尾；callSite与声明location分开。请求16KiB、最多100结果、items总192KiB、普通片段2000字符。

结果继续contractVersion=1，保留backend/status/snapshotId/sourceStamp/items/gaps/truncated/runtime/errorCode。CodeGraph返回candidate、semantic=false；历史semantic/confirmed数据保留原含义，不以新图重写。

## 3. 状态与精度

| 状态 | 含义 |
| --- | --- |
| ok/no-match | 操作成功/本次无匹配，不表示安全 |
| partial | 结构候选、覆盖缺口、截断或降级 |
| not-ready | 其他快照正在构建等容量限制 |
| timeout/cancelled | 超时/取消，没有补造成功 |
| unsupported | 未交付语言/操作 |
| failed | 后端、原文、身份或产物错误 |

GRAPH_STRUCTURAL_NOT_SEMANTIC是正常说明，合法图结果通常仍为partial。高confidence不等于类型语义；GRAPH_AMBIGUOUS_TARGET保留同参数数量重载，GRAPH_SYNTHESIZED_OMITTED说明合成成员省略。

## 4. 运行与降级

默认PI_AUDIT_QUERY_BACKEND=codegraph，可显式设basic，其他值拒绝。旧jdtls值也拒绝；Java环境变量不再被应用读取。

```powershell
Set-Location E:\pi-audit-harness\desktop
npm.cmd ci
npm.cmd run dev
```

首次建图使用npm平台包自带Node/SDK，关闭遥测、更新检查和并行解析池，不调用安装器/目录监听。完成后进程退出；热查询直接打开应用管理的只读投影，只缓存一份受限定位元数据。

构建失败可保留basic，但新任务固定本次降级身份与原因，不能悄悄升级。fallback=false观察原错误。快照损坏或图身份变化不能解释为无命中。旧路径和报告不由新图重写。

## 5. CLI

query:serve用PI_AUDIT_DATA_ROOT打开已有任务数据库。可信父进程注入随机PI_AUDIT_QUERY_TOKEN，服务仅输出ready/port；CLI继承相同token/端口，从stdin读一份JSON。

退出码映射为ok/no-match=0、partial=2、unsupported=3、not-ready=4、timeout=5、cancelled=130、其他=1。2不表示崩溃，应保留缺口。接口细节见[查询说明](../../desktop/query-skill/SKILL.md)，这份交付文档不自动注册或执行Skill。
