# pi-audit-harness · 源码审计客户端交互原型

直接用现代浏览器打开 `index.html`。无需安装依赖、启动服务器或配置后端，也不依赖 CDN、外部字体和图片。

## 视觉与布局

采用参考 Kali Linux 氛围的深海军蓝背景、青蓝强调色与冷色界面。模型配置、工具与环境页面使用完整宽度双栏布局。

## 页面与交互

- 项目总览：查看项目和审计记录，进入工作台。
- 新建审计：GitHub / 本地目录选择 → 模板与查询方式 → 确认运行。
- 模拟分析：进度、暂停、继续、停止和活动记录。
- 审计工作台：关键词搜索、状态筛选、风险选择、调用图节点点击、图形缩放、源码与证据查看。
- 人工复核：保存复核结论和审计备注，报告同步显示。
- 审计报告：查看路径、风险摘要和限制，下载可独立打开的 HTML 或 JSON。
- 漏洞模板：开关、编辑提示词、新建模板编辑器、Markdown / Skill 导入与实时预览。
- 模型配置：手动填写信息、OpenRouter 教程、主动模拟连接测试、保存与删除。
- 工具与环境：查看工具状态，模拟启停 Java LSP。
- 帮助中心：查看操作指南、结果说明及原型说明。

## 推荐体验路径

1. 在默认工作台切换六个风险点，点击调用链节点查看源码。
2. 打开“人工复核”，保存结论和备注，再进入“审计报告”。
3. 下载 HTML 报告并单独打开，查看内嵌路径图。
4. 点击“新建审计”，使用示例项目，走完三步流程，体验暂停、继续和停止。
5. 打开“模型配置”，查看手动配置教程；原型中使用 `demo-key` 等示例值。

## 模拟数据与本地状态

所有审计结果都是固定示例。不会下载 GitHub 仓库、上传源码、安装软件、调用模型或后端。新建项目展示同一组六个示例风险点，配置不会触发真实审计计算。

选择文件夹只使用浏览器提供的文件名和目录名，不读取文件内容。官方教程链接仅在用户主动点击时打开外部网页。

Markdown 导入仅在本地读取所选文档；Skill 目录仅读取 SKILL.md，关联脚本不会读取或执行。导入后可编辑名称、语言、分类、说明和审计步骤，预览后保存为模板。

浏览器 localStorage 保存模板、复核备注和模型配置元数据；API Key 只保存在当前页面内存中，刷新后清除。请勿在原型中输入真实密钥或敏感业务信息。浏览器限制本地文件存储时，页面仍可使用，但刷新后配置可能不保留。

帮助中心 → 关于原型 → “重置本地演示状态”可清除本原型保存的配置。新建项目和任务仅保留在页面内存中，刷新后恢复初始示例。
