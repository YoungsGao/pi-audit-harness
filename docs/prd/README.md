# pi-audit-harness · 产品需求

直接用浏览器打开 `index.html`，无需服务器或依赖。

## 两个页面

- **需求总览**：首版范围、需求数量与模块入口。
- **需求列表**：搜索、模块筛选、全部/首版/后续筛选。点击需求，在右侧查看详情。

右侧详情直接展示说明和验收条件；职责、参考阶段、前置关系及原文出处收在“实现备注与原文出处”折叠区。

右侧详情不阻止操作列表，可直接切换其他需求。点击关闭按钮或按 Esc 关闭。

全部 50 项需求保留（42 项首版、8 项后续）。原始 PRD 未修改。`requirements.json` 为内嵌数据的独立副本，页面不需要加载它。

本版本没有独立的依赖、排期、原文核对页面，也没有评审标记、导出和多视图入口。页面只用于阅读需求，不保存浏览记录或调用后端。

已检查脚本语法、两个页面、筛选、全部需求详情与关闭行为。真实浏览器视觉验收受当前环境限制。

首个开发任务为 ENV-01“构建 Electron 客户端骨架”：窗口、基础路由、进程职责与受控 IPC。Windows x64 为平台约束，安装包交付归入发布阶段 QA-03。
