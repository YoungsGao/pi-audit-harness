# Pi Audit Harness

基于 Pi 的代码审计与污点分析学习项目。

## 当前进度

- 已完成 Pi SDK 的基础调用练习。
- 已实现读取目标源码、生成接口说明。
- 已实现工具调用日志和分析报告保存。
- 已通过小型 Express 示例核对接口识别结果。

## 后续目标

- 明确第一阶段支持的语言和漏洞类型。
- 识别外部输入、危险操作及其数据流关系。
- 记录分析证据，区分疑似问题和已验证问题。
- 构建有漏洞版本与修复版本的对照测试。
