Project-authored code is prepared under the root MIT LICENSE. Dependencies retain their own licenses and notices.

The reproducible runtime inventory is generated by `node desktop/scripts/qa-compliance.mjs` after installing the locked desktop dependencies. It includes package-lock runtime components and dependencies embedded inside the installed CodeGraph platform package. Generated records and copied upstream license texts are in `desktop/resources/compliance`, and are shipped at `resources/compliance` in the Windows package.

Electron/Chromium notices are retained by electron-builder. The CodeGraph embedded Node 24.16.0 license is separately retained as `CODEGRAPH-NODE-LICENSE.txt`. An inventory of declared metadata is not a legal compatibility certification.

The 18 acceptance sources are independently authored. The pinned WebGoat source used for local QA is GPL-2.0-or-later and remains outside the distributed product. See [QA scope and source attribution](docs/technical/15.质量验收性能基线与交付.md).

The MCP adapters depend on the pinned official TypeScript MCP SDK (MIT); its runtime dependencies are included in the regenerated inventory. Semgrep 1.185.0 is an optional user-installed local scanner and is not bundled in the desktop installer. Its upstream license and dependencies must be reviewed separately if it is redistributed. Product-owned scan patterns remain project materials.

The local Python MCP runtime requires the official `mcp` 1.30.0 and Pydantic 2.12.5 (MIT), Starlette 1.8.0, Uvicorn 0.54.0 and HTTPX 0.28.1 (BSD-3-Clause), as declared by their installed distribution metadata. The Python source and pinned requirements are shipped; the interpreter and installed Python dependencies are supplied by the operator environment. No source from the archived standalone Semgrep MCP repository was vendored.
